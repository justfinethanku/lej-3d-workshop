# LEJ 3D Workshop — start here

This is the complete agent skill Jonathan Edwards uses, with the same public instructions and editable setup. Open [SKILL.md](SKILL.md), or ask your AI to read it. Keep this entire folder together: the main instructions link to detailed references and a reusable CadQuery verification script.

Place this folder in your agent's skills directory (for example `~/.codex/skills/` or `~/.claude/skills/`), or give another capable agent its SKILL.md path. Ask: “Read this skill, discover my available tools, and adapt the User config section to my workshop.” Your settings stay inside SKILL.md; no separate private edition is needed.

Read [setup](references/setup.md) for organization and config-preserving updates, and [CadQuery](references/cadquery.md) for installation and the executable verification workflow. CadQuery and other applications are installed separately. Fleet is optional; your own equipment and record system can replace the example setup.

Source, contributions, releases and MIT license: [GitHub repository](https://github.com/justfinethanku/lej-3d-workshop). The included VERSION identifies this bundle. Verify the ZIP with the release's SHA256SUMS before installation.
